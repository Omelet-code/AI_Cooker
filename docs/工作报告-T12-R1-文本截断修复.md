# T12 R1 文本截断修复报告

## 1. 目标

修复审查报告指出的 P2：`ModelGatewayServiceImpl.complete` 只在 JSON 分支拒绝 `finish_reason=LENGTH`，导致非空 TEXT 截断回复被当作成功结果。目标是在输出格式专属处理前统一拒绝截断，同时保留 JSON 正文语法校验。

## 3. 实现与测试取舍

- 在取出 `finishReason` 后、读取正文及进入 TEXT/JSON 专属校验前，以 `equalsIgnoreCase("LENGTH")` 统一映射为 `INVALID_RESPONSE`。
- JSON 语法验证保持独立；截断 JSON 即使正文语法看似有效也失败，`STOP` 但语法错误的 JSON 仍失败。
- 新增实际 Mock HTTP 回归：TEXT 小写/大写、JSON 小写/大写共四种非空截断响应。逐一验证 `INVALID_RESPONSE`、单次供应商请求、无 cause，且错误消息及捕获日志不含测试 Key、独特 Prompt 或原始供应商正文。
- 原有正常 TEXT/JSON、空响应和畸形 JSON覆盖未删除或放宽。
