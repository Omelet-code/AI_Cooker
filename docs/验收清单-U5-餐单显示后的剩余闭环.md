## 最小人工清单

1. 打开已有成功餐单：确认默认两套组合符合原要求，四菜一汤每套4道菜与1道汤，无同套重复；材料的原量/参考量/未知说明和本餐人数可辨认。若只产出一套，记录实际不足原因，不直接算双方案通过。
2. 点击其中一套生成指导：只使用所选菜，覆盖完整5道菜，包含材料准备、逐菜操作与合理顺序；没有混入另一套餐单。此点击会真实调用模型，沿用既有用户主动试用允许，不自动重复失败请求。
3. 审核内容：原菜谱事实与模型可选补充明确分区；材料用量不被偷偷更改，无编造的精确预算/整餐耗时/营养或诊疗承诺。评价步骤是否可做、表达是否像亲近的烹饪伙伴。
4. 刷新、退出再登录：能回看同一餐及已保存指导，不需要再次点击生成。将显示是否一致与是否无新增模型动作分别记录，后者由主架构只读核对。

请按1～4反馈通过或具体问题；失败时先提供会话/餐单与页面提示，不连续重试、不提供密钥。已有指导则优先回读，不为了清单再生成。
